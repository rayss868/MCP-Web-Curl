Folder ini memisahkan sumber publik, snapshot kerja lokal, metrik, bukti, figure, dan catatan audit yang dipakai untuk penyusunan tesis.

## Struktur
- `01_public_repo/`: clone repositori publik GitHub `rayss868/mcp-web-curl`.
- `02_working_tree_snapshot/`: snapshot source, scripts, package metadata, README, changelog, dan tsconfig dari folder kerja lokal.
- `03_metrics/`: salinan `metrics_runs.csv` dan `metrics_summary.json` yang sudah tersedia.
- `04_evidence/`: hasil pengujian/screenshot dan error log yang relevan.
- `05_figures/`: lokasi figure yang dipakai atau akan dipakai untuk Bab IV/V.
